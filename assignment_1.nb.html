Task 6: R Functions

1. A function calculating the ratio of the mean and the median of a vector

mean_over_median = function(x) {
  x = na.exclude(x) # removing NAs
  ratio = mean(x)/median(x)
  return(ratio)
}

# test
print(mean_over_median(c(2, 2, 3, 4, 5)))
[1] 1.066667

2. A function calculating the mean after discarding the min and the max

mean_without_extreme = function(x) {
  x = na.exclude(x)
  x = x[(x != min(x)) & (x != max(x))]
  
  return(mean(x))
}

# test
mean_without_extreme(c(1, 2, 2, 5))
[1] 2

3. Explaining “piping”

A pipe is discouraged when the included functions (1) have multiple inputs or outputs, (2) have a complex dependency, (3) use the current environment, or (4) use lazy evaluation. Besides, (5) piping too many intermediate steps/functions can make the code harder to read and debug.

4. Explaining “apply-family functions”

The apply-family functions are used to apply a function to each element in an iterable object. Though they won’t make the running more efficient, they replace a for-loop with a more compact code snippet. In other words, it seems like they only make the code look better.
